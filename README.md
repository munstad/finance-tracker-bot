# 💰 Finance Tracker Bot

Telegram-бот для учёта личных финансов. Пишешь трату обычным текстом —
бот сам определяет категорию, сохраняет в базу и по запросу строит
график расходов.

## Возможности

- Запись трат в свободной форме: `кофе 250`, `500 такси`
- Автоматическое определение категории по ключевым словам
  (еда, транспорт, развлечения, здоровье, одежда, жильё, прочее)
- Хранение данных в SQLite
- Команда `/report [дни]` — круговая диаграмма + столбчатый график
  расходов по категориям (по умолчанию за последние 30 дней)
- Команда `/undo` — отменить последнюю запись
- Поддержка нескольких пользователей одновременно

## Стек

Python 3.11+, aiogram 3, SQLite, pandas, matplotlib, python-dotenv

## Установка и запуск

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/munstad/finance-tracker-bot.git
   cd finance-tracker-bot
   ```

2. Создай виртуальное окружение и установи зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Получи токен бота у [@BotFather](https://t.me/BotFather) в Telegram
   (команда `/newbot`).

4. Скопируй `.env.example` в `.env` и вставь свой токен:
   ```bash
   cp .env.example .env
   ```

5. Запусти бота:
   ```bash
   python bot.py
   ```

6. Напиши своему боту в Telegram что-нибудь вроде `кофе 250`.
